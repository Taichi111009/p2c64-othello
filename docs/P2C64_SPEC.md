# P2C-64 確定仕様書（v2.0）
## SYGMA-SCONE 統合アーキテクチャ（完全手番相対 PTM ＆ 60手番平滑化ヘッド）
— 64パターン手番相対骨格 × 1分岐PTM展開 × 16B非対称ブロック統合 × 60手番平滑化非線形残差 —

### 1. v1.1 → v2.0 改修の背景（2,551万局面実測からの2大ブレイクスルー）
v1.1 の2,551万局面ベンチマークで判明した2つのボトルネックを一撃で解消する：
1. **土台 `LINEAR_64` の `-18.8 Elo` ハンデ撤廃**：6手ブロック共有 `corner_tempo[blk]` を廃止し、全64パターンを手番相対（Player-to-Move: PTM）の60手番独立骨格へ統一。`RAW_NTUPLE_64` と `LINEAR_64` を数理的に完全同一（ビット一致 `max_err = 0`）とする。
2. **6手境界段差による中盤 MPC $\sigma$ 悪化の根絶**：SCReLUヘッド（`mu`, `beta`）および SCONE-D Macro-LUT を **60手番独立テーブル** へ拡張し、学習時に **隣接手数平滑化正則化** と **隣接ブロック平滑化正則化** を導入する。

### 2. 共通骨格：完全手番相対（PTM）＆ 非対称メモリレイアウト（総容量 `50.43 MiB`）

| 項目 | 仕様（v2.0） | メモリ容量 |
| :--- | :--- | :---: |
| **探索中インデックス表現** | 絶対色 `{白=0, 空=1, 黒=2}` の差分更新を維持（手番反転更新コスト 0） | — |
| **PTM 変換（1分岐テンプレート）** | `evaluate_p2c64_ptm<MODE, IS_WHITE>`：<br>• 黒番 (`IS_WHITE=false`): `x = idx[p]`（演算 **0命令**）<br>• 白番 (`IS_WHITE=true`): `x = off_end - idx[p]`（減算 **1命令**のみ） | — |
| **比較基準 `RAW_NTUPLE_64`** | 全64パターン（`410,022` 状態）× 60手番 × `int16_t`（真のEgaroucid互換PTM） | **46.92 MiB** |
| **P2C-64 主要14ノード (`0..13`)** | 型 `0..3`（`C3x3`, `Edge+2X`, `Line2`, `Diag8`）・PTM `91,854` 状態 × `BlockEntry16` (16B整列) × 10ブロック | **14.02 MiB** |
| **P2C-64 非主要50ノード (`14..63`)** | 型 `4..15`・PTM `318,168` 状態 × `int16_t` (2B) × 60手番（直接参照） | **36.41 MiB** |
| **P2C-64 合計（骨格＋埋込）** | `14.02 + 36.41 MiB`（`RAW_NTUPLE_64` 比わずか **+3.51 MiB**） | **50.43 MiB** |

#### $D_4 \times \mathbb{Z}_2$ 全16変換の厳密保証
- $\mathbb{Z}_2$ 色反転 `(B, W, stm) -> (W, B, -stm)` で全64パターンの PTM インデックスが完全に不変となるため、$\mathbb{Z}_2$ 対称性は**制約ゼロで自動成立**する。
- 重み・埋め込み・コード・Macro-LUT の焼き込み時は **$D_4$ 内部鏡映不変性のみ**を強制すればよく、v1.1 の反鏡映不動点制約 `{6, 7}` は完全撤廃される。

### 3. `BlockEntry16`（16B整列・主要14ノード専用）と選択式非線形残差（v2.0）

```cpp
struct alignas(16) BlockEntry16 {
    int16_t w[6];   // 12B: 連続6手番分の PTM 線形重み W
    uint8_t aux[4]; //  4B: 主要14ノード専用の非線形残差データ
};
```

#### 候補A：`CAND_A_PTM_SCRELU4`（4チャネル手番相対 SCReLU・60手番ヘッド）
- **`aux[4]`**：`int8_t h[4]`（手番相対4チャネル埋め込み）。
- **7幾何領域への整数加算**：4本の辺ストリップ・2本の対角ストリップ・1つの全体和へ `h[0..3]` を直接加算。
- **60手番独立ヘッド（計 `2.81 KiB`、L1常駐）**：`int16_t mu[60][3][4]`、`int16_t beta[60][3][4]`（$|\beta| \le 2047$）。
- **分配法則くくり出し（理論 `imul` 40命令）**：
  $$u_{r,k} = \text{clamp}(h_{r,k} + \mu_{\text{ply}, g(r), k},\, 0,\, 127)$$
  $$A_{\text{res}} = \text{sym\_rshift}\!\left(\sum_{g=0}^{2}\sum_{k=0}^{3}\beta_{\text{ply},g,k}\left(\sum_{r \in \text{grp}(g)} u_{r,k}^2\right),\, 7\right)$$
  最大累積値 $7 \times 4 \times 127^2 \times 2047 = 924,449,764 < 2^{31}-1$（`int32_t` 絶対安全）。

#### 候補B：`CAND_B_PTM_3W3B`（乗算ゼロ・60手番 Macro-LUT・全8コード解放）
- **`aux[4]`**：`uint8_t code_fwd, code_rev`（下位3bit `0..7` 全8カテゴリ完全解放、余白2B）。
- **60手番独立 Macro-LUT（計 `180.0 KiB`、1手番 `3.0 KiB` でL1常駐）**：`T_CW[60][512]`, `T_EA[60][512]`, `T_CD[60][512]`（各 `int16_t`、$D_4$ 鏡映対称）。
- **`Key-14 First` スケジューリング**により非主要50ノードの2Bロードと10回のMacro-LUTロードを重複実行し、カーネル全体の **`imul` 厳密 0 命令** を維持。

#### 候補C：`CAND_C_PTM_HYBRID`（2チャネル PTM SCReLU ＋ 60手番 3way-3bit）
- **`aux[4]`**：`int8_t h[2]`（2B）＋ `uint8_t codes`（`fwd:3b | rev:3b` ＝ 1B）＋ `uint8_t reserved`（1B）。
- 候補Aの2チャネル版（60手番ヘッド `1.41 KiB`、**`imul` 20命令**）＋ 候補Bの60手番 Macro-LUT（10参照・`Key-14 First`）。

### 4. 学習パイプライン ＆ 境界段差解消正則化
1. **Phase 1（1回のみ学習）**：全64パターン×60手番のPTM重み $W$ を Huber損失 ＋ 隣接手数平滑化 $\lambda_{\text{sm}}\sum_{t=1}^{59}\|W_t - W_{t-1}\|_2^2$ で学習し、同一重みを `raw_ntuple64.p2c` と `linear64.p2c` 双方へ書き出す。
2. **Phase 2（Zero-Init Residual・$W$ 完全凍結）**：
   - **候補A**：60手番ヘッド（`beta, mu`）への隣接手数平滑化 ＋ 10ブロック埋め込み `h[10]` への隣接ブロック平滑化 $\lambda_{\text{blk}}\sum_{b=1}^{9}\|h_b - h_{b-1}\|_2^2$ ＋ QAT。
   - **候補B**：Soft多重線形テンソル縮約（隣接ブロックロジット平滑化＋隣接手数LUT平滑化）→ 60手番隣接手数平滑化付き MM型 Empirical Bayes 縮小再学習（Convex Refit）→ Exact EM-LUT 座標降下。
   - **候補C**：2チャネル PTM SCReLU を収束・凍結後、残差へ60手番 3way-3bit パイプラインを適用。
3. **`.p2c` バイナリフォーマット v2.0**：マジック `P2C64V20`、`version = 2`、64Bヘッダ＋FNV-1aチェックサム。既存の20B学習データバイナリ（`train.bin` / `val.bin`）は再加工なしで100%互換。
